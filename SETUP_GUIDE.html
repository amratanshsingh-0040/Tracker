Expense Tracker Setup Guide

Step-by-step installation for non-technical users · Zero coding needed

Beginner Friendly

💡 2 Important Things to Know First:

1. Do you need to install React separately? No. React is automatically installed when you run the 1-click setup command in Step 3.

2. Do you need MySQL or MySQL Workbench? No! The project uses an embedded SQLite database that starts automatically. You do NOT need to set up any database server or passwords.

Part 1: Install the 3 Free Tools (One-Time Only)

1. Install Node.js (JavaScript Runtime) https://nodejs.org

  1. Go to https://nodejs.org and download the LTS (Recommended) version.
  2. Open the downloaded installer file (.msi on Windows, .pkg on Mac).
  3. Click "Next" on all screens, accept the license, and click "Install".
  4. Once finished, click "Finish".

2. Install Git (To Download the Code) https://git-scm.com/downloads

  1. Go to https://git-scm.com/downloads and click Windows (or macOS).
  2. Open the downloaded installer.
  3. Keep clicking "Next" on all screens with standard default settings.
  4. Click "Install", then click "Finish".

3. Install Visual Studio Code (VS Code) https://code.visualstudio.com

  1. Go to https://code.visualstudio.com and click "Download for Windows" (or Mac).
  2. Run the installer, click "Next", check "Create a desktop icon", and click "Install".
  3. Launch VS Code once the installation completes.
Part 2: Download (Clone) the Project from GitHub
  1. Open VS Code on your computer.
  2. Open the terminal by pressing Ctrl + ~ (or click Terminal > New Terminal at the very top menu).
  3. Navigate to where you want the project (for example, your Desktop): 
    cd Desktop
  4. Download the project from GitHub (replace with your repository link): 
    git clone <PASTE_YOUR_GITHUB_REPO_URL_HERE>
  5. Enter the project folder: 
    cd Tracker

Part 3: 1-Click Installation (Runs Once)

In that same VS Code terminal inside the Tracker folder, run this single command:

npm run setup

⏳ What happens: Your computer will download and configure all packages (including React and backend tools). This takes about 1 to 2 minutes. Wait until your prompt reappears.

Part 4: Start the Tracker & Open in Browser 🚀

Whenever you want to run the application, simply type:

npm run dev

💡 Windows Shortcut: You don't even need VS Code open! You can just go to the Tracker folder on your Desktop and double-click the start.bat file.

Open your browser (Chrome, Edge, or Brave) to:
👉 http://localhost:3000

What You Want to Do How to Do It
Record an Expense Click "+ Add Expense" in the top right. Enter amount in ₹ (INR), who you paid, category, and attach receipt bill (PDF or photo).
View / Download Receipts Click any receipt thumbnail in the table to open full invoice popup with zoom and download buttons.
Add 1–2 Team Members Click "Team" in the top navigation bar > type Name, Email, Password > click "Add Person". (Admins only).
Check Overdue Reminders Items pending for 5+ days alert you in a yellow banner or via the 🔔 bell icon in the top right.
Stop the App In the terminal window, press Ctrl + C (or just close the terminal window).
Start Tomorrow Run npm run dev (or double-click start.bat) and visit http://localhost:3000.
